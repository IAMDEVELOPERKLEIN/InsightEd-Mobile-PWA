Infrastructure Migration Report

Project: InsightEd PWA (STRIDE Infrastructure)
Administrator: Clea Sacriz
Date: April 2026

1. Migration Objective

To eliminate database latency and prepare the InsightEd ecosystem for a massive rollout of 2,000+ concurrent users by migrating PostgreSQL from a remote Azure instance to a high-performance local environment on STRIDE-PROD-VM-01.

2. Storage Architecture & Partitioning

Prior to migration, the OS partition was at critical capacity (100%). We implemented a decoupled storage strategy to ensure long-term stability.

295 GB Managed Disk
/mnt Mount Point
5 GB+ Reclaimed Space
84% OS Utilization
Data Relocation: Successfully moved the PostgreSQL data directory from /var/lib/postgresql/16/main to /mnt/postgres_data, ensuring write operations do not impact OS stability.

3. Database Performance Tuning

Parameters were recalibrated to utilize the 16GB server RAM effectively, prioritizing fast retrieval of inventory and teacher data.

Parameter Optimized Value Purpose
shared_buffers 4 GB Allows 25% of RAM to keep "hot" data in-memory.
work_mem 16 MB Handles complex inventory sorting and joins without disk hits.
effective_cache_size 12 GB Optimizes query planner for OS-level file caching.

4. Concurrency Management (PgBouncer)

A PgBouncer middleware was implemented on port 6432 to act as a connection pooler between the PWA application and the PostgreSQL backend.

This configuration recycling database sessions allows thousands of teachers to access the site simultaneously while maintaining a stable, low-overhead number of active database processes.

5. Final Infrastructure State

Server RAM 16 GB (Healthy Utilization)
DB Storage (/mnt) 295 GB (4% Used)
System Storage 29 GB (4.7 GB Free / 84% Utilization)
Network Mode Local Loopback (Near-zero latency)
