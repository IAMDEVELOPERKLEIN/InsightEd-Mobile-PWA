Technical Summary: Adding a New Division

System: InsightEd Mobile PWA | Subject: Carmona City Integration

This guide outlines the "Anchor Row" methodology used to integrate **Carmona City** as a new Division under **Region IV-A**, ensuring immediate availability in cascading dropdowns without performing a full data migration of individual schools.

1. The Data Architecture

The location hierarchy in InsightEd is primarily driven by two database tables queried via api/index.js:

  • schools_IERN: The master source for physical school locations (Region, Division, District).
  • all_locations: A reference table used for Municipality-to-Division mapping.

2. Implementation Steps

Step A: Provisioning the Anchor Row (Division/District/School)

To enable the **Division** and **District** selections, a placeholder entry was added to schools_IERN. This acts as a "seed" record that the backend API picks up during DISTINCT queries.

INSERT INTO "schools_IERN" ("SchoolID", "School_Name", "Region", "Division", "District", "Municipality", "Province") VALUES ('SDO-164000', 'Carmona City Placeholder', 'Region IV-A', 'Carmona City', 'Carmona City', 'CARMONA', 'CAVITE');

Step B: Enabling Municipality Lookup

The system uses all_locations to lookup valid municipalities for a specific division/district. An entry was added to link the CARMONA municipality to our new Carmona City division.

INSERT INTO all_locations (region, division, district, municipality, province) VALUES ('Region IV-A', 'Carmona City', 'Carmona City', 'CARMONA', 'CAVITE');

3. Cascading Dropdown Verification

The following API endpoints (located in api/index.js) were verified to consume the new data automatically:

  • /api/locations/divisions?region=Region%20IV-A → Returns Carmona City
  • /api/locations/districts?division=Carmona%20City → Returns Carmona City
  • /api/locations/municipalities?district=Carmona%20City → Returns CARMONA
  • /api/locations/schools?municipality=CARMONA → Returns SDO-164000
Strategy Advantage: This approach allows "Carmona City" to be selectable in registration and dashboards immediately. Actual schools can be migrated from the "Cavite" division to "Carmona City" at a later date by updating their Division field in the database.

4. Security Enforcement

As part of this update, the Passcode Setup flow was made mandatory by removing the "Remind me later" trigger from src/components/PasscodeSetupPrompt.jsx, ensuring all new Carmona City (and existing) accounts are secured upon first login.
