01

Installation of PWA

InsightEd is a Progressive Web App. No app store needed—just direct, high-performance access.

iOS ACCESS (SAFARI)

  • 1. Open tinyurl.com/InsightEdV2
  • 2. Tap the "Share" icon (square with arrow up)
  • 3. Scroll down and select "Add to Home Screen"
  • 4. Tap ADD in the top right

ANDROID ACCESS (CHROME)

  • 1. Open tinyurl.com/InsightEdV2
  • 2. Tap the "Three Dots" menu button
  • 3. Select "Install App" or "Add to Home Screen"
  • 4. Confirm by tapping INSTALL
