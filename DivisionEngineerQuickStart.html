Installation of PWA

InsightEd is a Progressive Web App. No app store needed—just direct access.

iOS ACCESS (SAFARI)

  • 1. Open tinyurl.com/InsightEdV2
  • 2. Tap "Share" icon (square with arrow up)
  • 3. Select "Add to Home Screen"
  • 4. Tap ADD in the top right

ANDROID ACCESS (CHROME)

  • 1. Open tinyurl.com/InsightEdV2
  • 2. Tap "Three Dots" menu button
  • 3. Select "Install App"
  • 4. Confirm by tapping INSTALL

2. Projects: Site Operations Hub

In the projects tab, you will see a list of projects displayed through cards. Each card contains key project information at a glance.

"To see the detailed project information, the user must click the card."

Within the card, you will also see the procurement status. You must change it depending on the stage of the project. You also have to update the procurement details by clicking the update button.

STATUS TRANSITION: Once the procurement status is completed, you can now change the construction status.

Construction updates must be performed regularly. Site photos are mandatory for COA compliance. After uploading photos, you can update the percentage status.

Finally, by clicking the LOGS button, you can view the complete history of updates.
